# Public repository rules

This repository is the public Fusion MCP prototype. Internal project work does not belong here.

Never add any of the following:

- Internal or private files, including review notes, validation logs, authorization notes, and handoff notes
- Ledgers, working-state notes, or agent-instruction files from the private project (`ledger/`, `CURRENT.md`, `AGENTS.md`)
- Personal paths or identifiers: a home-directory path, an OneDrive path, a machine name, an email address, or a desktop-client package id. Use a placeholder such as `C:\AI-Make\...`, `%USERPROFILE%`, or `%APPDATA%`
- Credentials, tokens, API keys, host configuration, job databases, checkpoints, or CAD from a real project
- Approval notes, or text that records a person authorizing an install, a push, or a release
- Links or copies that point at a private repository, a private folder, or an unpublished review archive

Internal material lives in the private AI_MAKE repository. If a note is only useful inside that project, leave it there.

When you are unsure, leave it out.
